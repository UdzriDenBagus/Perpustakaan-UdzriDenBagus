# 📚 Perpustakaan Udzri

**Perpustakaan Udzri** adalah proyek website perpustakaan sederhana yang dikembangkan sebagai sarana pembelajaran dasar pengembangan web. Website ini menampilkan antarmuka untuk melihat informasi buku, pegawai, dan pengunjung perpustakaan.

Proyek ini dibuat untuk melatih keterampilan dalam menggunakan HTML untuk menyusun struktur halaman dan CSS untuk mengatur tampilan website.

## ✨ Fitur Website

- **Halaman Login** — menyediakan tampilan formulir login untuk pengguna.
- **Dashboard** — menampilkan halaman utama dan navigasi website.
- **Daftar Buku** — menampilkan informasi buku, penulis, penerbit, dan gambar sampul.
- **Data Pegawai** — menampilkan informasi pegawai perpustakaan.
- **Data Pengunjung** — menampilkan informasi pengunjung perpustakaan.
- **Navigasi Menu** — memudahkan pengguna berpindah antarhalaman.

> Catatan: Proyek ini masih berupa website statis. Formulir login belum menerapkan verifikasi akun, dan data yang ditampilkan masih berupa data contoh yang ditulis langsung di dalam HTML.

## 🛠️ Teknologi yang Digunakan

- **HTML5** — membangun struktur halaman website.
- **CSS3** — mengatur tata letak, warna, tipografi, dan tampilan elemen website.
- **Boxicons** — menyediakan dukungan ikon pada halaman login.

## 🚀 Cara Menjalankan Proyek

1. Unduh atau clone repository ini ke komputer.
2. Ekstrak folder proyek jika diunduh dalam format ZIP.
3. Buka folder `perpus_Udzri` menggunakan Visual Studio Code.
4. Buka file `Login.html` melalui browser, atau gunakan ekstensi Live Server di Visual Studio Code.
5. Jelajahi halaman login, dashboard, daftar buku, pegawai, dan pengunjung melalui menu navigasi.

Proyek ini tidak memerlukan instalasi database atau backend untuk melihat tampilan halaman yang tersedia.
